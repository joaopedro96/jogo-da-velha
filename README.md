# jogo-da-velha
Implemente o Jogo da Velha em Java para 2 jogadores em um tabuleiro 3x3. Cada jogador marca casas alternadamente com "O" ou "X". O programa deve validar jogadas, impedir casas já ocupadas ou inválidas, imprimir o tabuleiro após cada jogada e verificar vitória ou empate, finalizando quando o jogo terminar.
